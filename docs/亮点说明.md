# 亮点说明

《可视化导论》课程实践学习网站 · 交付说明

---

## 一、一句话概括

这不是一份把讲义搬上网页的材料，而是一本**会动的参考书**：十一章正文里的每一张图都真实运行在页面上，
读者可以拖动、悬停、切换参数，看到映射方式改变时结论如何改变。全站零图片素材、零构建步骤、零框架依赖。

---

## 二、核心亮点

### 1. 首页：同一批数据点的六种组织方式

封面不是一张图片，而是一个三万颗粒子的实时渲染场（three.js 自定义着色器）。六种状态连续变形：
**散点云 → 坐标纸 → 柱群 → 平行轴 → 网络 → 地球**。这正是"数据处理"的过程本身——
同一批记录，被组织成六种可读的形状。粒子按各自的延迟出发，迁移过程有先后与弧线，
可以拖动旋转、双击暂停自动巡演，右侧阶段梯可随时跳转。

同一逻辑延伸到首页演示区：**"同一份数据的四种画法"**——位置、长度、顺序、面积四种编码之间连续变形，
数据一行未改，读者亲眼看到"映射方式决定了你能读到什么"。

### 2. 内容与图形一一对应：知识 → 代码 → 图

每一节都遵循同一结构：先讲清一个概念，给出产生该图形的可运行代码，再把图形交给读者操作。

- 33 张交互图，全部用 Canvas 2D 实时绘制，没有一张是图片。
- 代码块（Python / JavaScript）与图上行为严格对应，可复制、无冗余注释。
- 图注写的是"这张图让你看到什么"，图号由网站自动生成。

### 3. 交互设计服务于概念，不是装饰

每个交互都对应一个具体的教学点：

| 图 | 读者动手做什么 | 学到什么 |
| --- | --- | --- |
| 前注意搜索 | 在点阵里找那个不同的点，系统计时 | 颜色/形状搜索用时几乎与干扰项数量无关，颜色+形状的组合搜索则随时数线性上升 |
| 韦伯定律 | 拖动长度差，看阈值线 | 刚能分辨的差值与基准长度成比例（韦伯分数约 1/42） |
| 数据清洗 | 切换四种处理，看统计量变化 | 填补、剔除、换算、去重分别如何改变 n、均值与标准差 |
| 标记与通道 | 选标记 + 选通道，共 20 种组合 | 哪种组合成立、哪种勉强、哪种根本不成立 |
| 数据墨水比 | 拖动滑杆逐步去掉装饰 | 墨水比由浏览器**现算像素**得出，不是预设数字 |
| 表达性/有效性 | 点通道排序看判别实验 | 位置 > 长度 > 角度 > 面积 > 灰度（Cleveland & McGill 1984） |
| 平行坐标 | 在任意轴上拖动刷选 | 多维查询就是各轴区间条件的交集 |
| 力导向网络 | 拖动节点、重新初始化 | 布局没有唯一解，取决于初始位置 |
| 焦点+上下文 | 移动指针用鱼眼放大 | 细节与全局同屏的代价是位置失真 |
| 语义缩放 | 滚轮换层 | 换掉的是数据表示法，不是像素分辨率 |
| 正确但误导 | 三个开关翻转 | 同一份数据得出"1%"或"10%"两种印象，谎言因子现算 |

### 4. 原生中英双语，不是机翻

- 全站文案在数据层分离，切换语言不刷新页面，正文、图注、控件、导航、日期同时更新。
- 英文是同等信息量的独立写作，术语使用通行英文表述（visual encoding、pre-attentive processing、
  brush and link、lie factor 等），不是逐字直译。
- 中文页面在标题下同时保留英文标题，反之亦然——方便学生对照专业词汇。

### 5. 一份克制到极致的视觉语言：两种油墨

设计要求"知识性文本用黑白配"，因此整个站点只有**两种油墨**：

- **黑**：正文、标题、图形主色，从 `#141414` 到 `#a6a6a6` 的灰阶承担全部层次。
- **红** `#b4232a`：唯一的强调色，用于交互反馈、当前状态、高亮数据。来源是 1869 年 Minard 东征流量图的
  双色印刷传统——可视化史上最著名的图，本身就只用黑与红。

没有圆角卡片、没有投影、没有渐变底、没有彩色气泡框。层次靠字重、灰度与发丝线区分，
图形角上有印刷规矩线，图版比文字栏更宽（940px / 680px），像一本排过版的图册。
正文用衬线体（Spectral + 思源宋体），界面用无衬线（IBM Plex Sans），行距按中文阅读习惯放宽到 1.9。

### 6. 十一张图形概览

绪论（流程、Anscombe 四组数据、简史时间线）、视觉感知（格式塔分组、前注意搜索、韦伯定律）、
数据（测量尺度、清洗、分布概括）、任务（三分法环、动作×目标矩阵、概览优先）、
设计（标记×通道、通道有效性、数据墨水比）、高维（平行坐标、散点图矩阵、主成分投影）、
时序（折线查询、流图基线、动画轨迹）、地理（投影变形、分级设色、流场）、
层次与网络（三种层次布局、力导向、桑基图）、交互（鱼眼、刷选联动、语义缩放、可视分析循环）、
评估（两条件对比、正确但误导）。

### 7. 工程上真正做到了"打开就能用"

- **零依赖安装**：没有 npm、没有打包器，经典脚本 + CSS，`file://` 直接双击可用。
- **离线可用**：three.js 与陆地轮廓数据都内置在仓库里；字体走 CDN 并带系统字体回退。
- **性能**：动画只在画布进入视口时运行，离开即停；页面隐藏时全部暂停。
- **健壮性**：首帧同步绘制，因此在不支持动画、后台标签页或旧浏览器里，图形依然是完整可读的一张图；
  WebGL 不可用时封面自动退回 2D 投影；尺寸变化后立即补画，不会出现空白图版。
- **无障碍**：键盘可达、焦点可见、颜色对比达标，尊重系统的"减弱动态效果"设置。
- **开发工具**：`dev-figures.html` 一次挂载全部 33 张图，用于回归检查。

| 时间 | 画面 | 讲解要点 |

| 0:00–0:25 | 封面点阵，拖动旋转，点右侧阶段梯跳转 | "同一批数据点的六种组织方式"——数据从散点到地球的六种形状 |
| 0:25–0:50 | 首页目录，悬停章节行看缩略图动画 | 十一章、四十九节、三十三张图；每章一张微缩图 |
