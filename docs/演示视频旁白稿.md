# 演示视频旁白稿（4 分钟版）
# 每段独立合成，时长以实际音频为准，画面按音频长度对齐。

## S1 封面（约 25s）
这是《可视化导论》的课程实践学习网站。封面不是一张图片，而是三万颗粒子的实时渲染。同一批数据点，六种组织方式：散点云、坐标纸、柱群、平行轴、网络，最后收拢成地球。右侧可以随时切换状态，画面也能直接拖动旋转。

## S2 目录（约 25s）
向下是第一级目录：十一章，四十六节，三十三张交互图。每一行悬停时会画出一张微缩图，那是这一章的核心图型；右侧标出了每章的图数与预计阅读时间。整本站按知识、代码、图形三段式组织，每一节都可以独立进入。

## S3 四种画法（约 30s）
首页放了一个直接可以玩的演示：同一份数据，四十二座城市的人口，四种画法。条形图用长度编码，散点图用位置，折线图用顺序，气泡图用面积。数据一行都没有变，变的只是映射方式，而你能读到的结论就完全不同了。这就是整门课要讲的事情。

## S4 视觉感知（约 40s）
第二章讲视觉感知。格式塔原则这一张，是同一批点经过五种分组方式，可以看到接近、相似、连续、连通、闭合各自如何决定人看到的分组。前注意处理做成了一次搜索游戏：在七百个点里找出那个不同的点，系统会记录用时。颜色和形状可以并行搜索，用时几乎与点的数量无关；而颜色加形状的组合搜索只能一个个排查，用时会明显上升。最后是韦伯定律：刚能分辨的长度差与基准长度成比例，长度判断的韦伯分数大约是四十二分之一。

## S5 数据与设计（约 40s）
第三章到第五章是数据与设计。清洗这一张切换四种处理：填补缺失值、剔除异常值、统一单位、去掉重复记录。每换一种，下面的样本数、均值和标准差都会跟着变，清洗从来不是中立的。第五章讲视觉编码：选一种标记，再选一个通道，二十种组合里哪些成立、哪些勉强、哪些根本不成立，图里会直接告诉你。数据墨水比更有意思：拖动滑杆逐步去掉阴影、立体、网格和边框，比值是浏览器实时数像素算出来的，不是预设的数字。

## S6 按数据类型展开（约 40s）
第六章到第九章按数据类型展开。高维数据用平行坐标：在任意一根轴上拖动刷选，就是一次多维条件查询。地理空间的难点是投影：墨卡托保持方向，却让面积随纬度剧增；等面积投影保住了面积，却压扁了形状。没有两全的方案，只有取舍。层次与网络里，矩形树图、旭日图和径向树是同一棵树的三张脸；力导向布局没有唯一解，拖动节点，整张网会重新找一个稳定的形状。

## S7 交互与评估（约 25s）
第十章和第十一章讲交互与评估。鱼眼把放大限制在一个区域里，让细节和全局同屏；语义缩放换掉的不是分辨率，而是数据本身。最后一章这张图叫正确但误导：六个数字从未改变，截断纵轴、改用面积，或者画成折线，同一个百分之一的变化，看起来可以像百分之十。

## S8 双语与收尾（约 15s）
右上角可以随时切换中英文，正文、图注和控件会一起改变。全站没有一张图片素材，三十三张图全部由浏览器实时绘制；纯静态，零依赖，也可以离线打开。
